# refs/ —— 角色参考图（图生图用的“角色卡”）

出图服务命中触发词时，会读这里的图当**条件图**交给 Qwen-Image-2.1，
再加一段固定的角色描述前缀（`DRAW_CHAR_TEMPLATE`），让「蓝色大肥鱼」每次都是同一个角色。

## 触发规则

群里/控制台说这些话，就会自动走图生图（不命中就还是纯文生图）：

```
大肥鱼 / 鲸鱼娘 / 鲸鱼妹妹 / 小鲸鱼 / 蓝色鲸鱼 / deepseek娘 / 画自己 / 画个自己 / 画一只自己
```

判定在 `draw-model/server.py` 的 `resolve_ref()`：
**请求里的 `ref` 参数 > `refs/default.txt` > 目录里按文件名排序的第一张**。
词表用环境变量 `DRAW_TRIGGERS` 覆盖，整个功能用 `DRAW_IMG2IMG=0` 关掉。

## 换图/加图

1. 直接往这个目录丢 `.png` / `.jpg` / `.jpeg` / `.webp`，文件名只用字母数字和 `-` `_`；
2. 想让它当默认：改 `default.txt` 里那一行文件名（或设 `DRAW_REF=xxx.png`）；
3. 单次指定：请求里带 `{"ref": "dfy-fullbody.png"}`，带 `{"ref": "none"}` 强制文生图。

## 注意事项

- **图里别留文字**：参考图上的字会被一起学进输出（Qwen-Image 画中文很准）。这批图已裁掉气泡，
  只留下一点点装饰符号。
- **构图会被参考图带偏**：这个管线的条件图没有 `strength` 旋钮，参考图是“整张图一起进视觉槽”，
  所以想要大变化（换姿势/换场景）就在 prompt 里把差异写清楚，必要时换一张构图接近的参考图。
- **授权**：这张是从公开的二创/表情包合集里挑的（DeepSeek 蓝鲸 logo 的民间拟人化形象），
  自用没问题；要商用或公开发布请自行确认原作者授权，或自己画/自己拍一套替换掉。
- 中间产物（抓图缓存、拼图预览）不要提交，`.gitignore` 已覆盖 `_raw*/` `_norm/` `_grid/` `_contact*`。
