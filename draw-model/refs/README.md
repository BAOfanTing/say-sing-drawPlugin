# refs/ —— 角色参考图（图生图用的「角色卡」）

出图服务命中触发词时，会读这里的图当**条件图**交给 Qwen-Image-2.1，
再拼一段该形态专属的角色描述前缀，让「蓝色大肥鱼」每次都是同一个角色、同一种画风。

## 三种形态（说哪个词就用哪张图 + 哪套模板）

| 触发词 | 参考图 | 形态 | 画风模板 |
|---|---|---|---|
| `小鲸鱼` | `dfy-small.png` | Q 版 chibi（头身比约 1:2、大头小身） | Q 版动漫插画、赛璐璐上色 |
| `大鲸鱼娘` | `dfy-large.png` | 正常人体比例少女（约 6-7 头身） | 动漫插画、清晰线稿 + 赛璐璐 |
| `真人鲸鱼` | `dfy-people.png` | 真人化（写实摄影质感，非二次元脸） | 真人 cosplay 摄影、柔和自然光 |

映射在 `draw-model/server.py` 的 `DEFAULT_REF_MAP`；**改词不用改代码**，设环境变量
`DRAW_REF_MAP` 为同样形状的 JSON 即可（值可以是文件名，也可以是 `{"ref": "...", "template": "..."}`）：

```powershell
$env:DRAW_REF_MAP = '{"小鲸鱼":"dfy-small.png","大鲸鱼娘":{"ref":"dfy-large.png","template":"…场景："}}'
```

匹配规则：**最长触发词优先**（`大鲸鱼娘` 先于 `鲸鱼娘`，不会被短词吃掉）。

除了三个主词，还挂了一批**同义词兜底** —— 模型改写 prompt 时经常换说法：

| 形态 | 除主词外还认 |
|---|---|
| 真人（people） | `真人鲸鱼娘` / `真人版` / `真人` / `写实` / `摄影` / `照片` / `cosplay` / `cos` |
| Q 版（small） | `小鲸鱼娘` / `Q版` / `chibi` / `迷你` |
| 少女（large） | 没加别名：`鲸鱼娘` / `大肥鱼` 这些通用词本来就落到 `default.txt`（= `dfy-large.png`） |

> 实测教训：群里说「画张真人鲸鱼娘…」，模型改写 prompt 时把「真人」两个字删了，只留「鲸鱼娘」，
> 结果画成了大鲸鱼娘。所以**除了这批同义词，人设里还得要求它把形态词写进 prompt**（两边都做才稳）。

### 服装

三个模板里的服装是单独一段，写着「**若场景描述了别的服装（睡衣、浴袍、泳装、日常服等），以场景为准**」——
因为参考图的衣服会被条件图一起带进来。实测：不加这句时，「穿睡衣」也会画回深蓝女仆裙；加了之后颜色/款式会跟场景走，
但**围裙形状还是会被参考图拽住**。要彻底换装，最稳的是给那个场景单独加一张参考图（`DRAW_REF_MAP` 里挂个词）。

## 兜底：通用触发词

命中下面这些通用词、又没有匹配到上面三张形态图时，用 `default.txt` 里那张（现在是
`dfy-large.png`）+ 内置的 `DRAW_CHAR_TEMPLATE`：

```
大肥鱼 / 鲸鱼娘 / 鲸鱼妹妹 / 小鲸鱼 / 蓝色鲸鱼 / deepseek娘 / 画自己 / 画个自己 / 画一只自己
```

都没命中就走文生图（不带参考图）。词表用 `DRAW_TRIGGERS` 覆盖，整个功能用 `DRAW_IMG2IMG=0` 关掉。

## 判定顺序

`请求里的 ref 参数（调试用）` → `触发词映射（三形态）` → `通用触发词 + default.txt` → 文生图。
带 `{"ref": "none"}` 强制文生图。

## 换图 / 加第四种形态

1. 往这个目录丢 `.png` / `.jpg` / `.webp`，文件名只用字母数字和 `-` `_`；
2. 在 `DRAW_REF_MAP`（或 `server.py` 的 `DEFAULT_REF_MAP`）里加一条：`"新触发词": {"ref": "新图.png", "template": "…场景："}`；
3. 想改兜底图：改 `default.txt` 里那一行文件名（或设 `DRAW_REF=xxx.png`）。

## 注意事项

- **图里别留文字**：参考图上的字会被一起学进输出（Qwen-Image 画中文很准）。
- **构图会被参考图带偏**：这个管线的条件图没有 `strength` 旋钮，参考图是「整张图一起进视觉槽」，
  所以想要大变化（换姿势/换场景）就在 prompt 里把差异写清楚；三种形态的立绘都是正面全身站姿，
  想拍近景/侧身时描述要写足。
- **比例按参考图算**：`size` 只给一个数时，输出宽高按参考图长宽比铺满 `size²` 的面积
  （`dfy-small` / `dfy-large` 是 2:3 竖图，`dfy-people` 约 3:4）。
- **文件格式要和扩展名一致**：`dfy-people.png` 原本是 WEBP 内容改了名，已转成真 PNG ——
  按扩展名判断的工具（看图器等）会读不了。
